# 🔐 Login System + Dashboard (Vanilla JS)

Este projeto é uma aplicação web desenvolvida em JavaScript puro (Vanilla JS) com o objetivo de estudar, na prática, tanto o desenvolvimento de sistemas quanto vulnerabilidades reais de segurança.

## 🚀 Objetivo

Construir um sistema funcional de autenticação e dashboard, explorando todo o ciclo:

* Implementação de login e controle de sessão
* Manipulação de DOM e eventos
* Uso de armazenamento local (localStorage)
* Simulação de API
* Exploração de vulnerabilidades
* Correção com boas práticas de segurança

## 🧩 Funcionalidades

* Sistema de login com validação de usuário
* Gerenciamento de sessão no navegador
* Renderização dinâmica de dashboard
* Estrutura modular (separação por responsabilidade)

## 🧠 Tecnologias

* JavaScript (Vanilla)
* HTML
* CSS
* localStorage (simulação de banco de dados)
* Módulos ES6

## 🤖 Uso de IA no desenvolvimento

Ferramentas como ChatGPT e Claude foram utilizadas como **copilotos de apoio**, auxiliando em:

* Direcionamento técnico
* Identificação de vulnerabilidades
* Revisão de arquitetura

No entanto, toda a **lógica, implementação e código foram desenvolvidos manualmente**, com foco em aprendizado prático e domínio real das tecnologias.

## ⚠️ Segurança (Importante)

Este projeto contém **vulnerabilidades intencionais**, utilizadas para estudo e aprendizado, incluindo:

* Session Forgery (falsificação de sessão)
* Armazenamento inseguro de dados
* Possíveis cenários de XSS (Cross-Site Scripting)

O objetivo é entender como essas falhas acontecem e como corrigi-las posteriormente.
